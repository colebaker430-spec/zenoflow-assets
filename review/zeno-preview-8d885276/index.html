3 free tools we use every day

We run 100+ AI tools and skills inside ZenoFlow. These three are our favorites. They're free and work in Claude Code and Codex.

/watch Claude watches videos

Hand it a video link or file. It pulls the frames and the transcript, so Claude can tell you what's in it and answer questions about it.

Use it for: breaking down a competitor's ad, turning a training video into written steps, pulling hooks from reels that are working.

Claude Code

/plugin marketplace add bradautomates/claude-video
/plugin install watch@claude-video

Codex

codex plugin marketplace add bradautomates/claude-video
codex plugin add watch@claude-video

Open source: github.com/bradautomates/claude-video

Playwright Claude uses a real browser

Claude opens websites, clicks, fills in forms and reads pages for you, the same way you would.

Use it for: checking your own booking form still works, pulling prices or listings from sites, filling out the same web form every week.

Claude Code

claude mcp add playwright npx @playwright/mcp@latest

Codex

codex mcp add playwright npx "@playwright/mcp@latest"

Needs Node.js 18 or newer. From Microsoft: github.com/microsoft/playwright-mcp

Humanizer Writing that sounds like you

It rewrites AI-sounding text so it reads like a person wrote it, without changing what it says.

Use it for: customer emails, replies, posts and anything else people can tell was written by a robot.

Claude Code

/plugin marketplace add blader/humanizer
/plugin install humanizer@humanizer

Codex

npx skills add blader/humanizer --global --agent codex

Open source: github.com/blader/humanizer
